# Domain Logsheets

Add logsheets inside the domain and duration folder that matches the internship period:

```text
public/logsheets/<domain-slug>/1-month/
public/logsheets/<domain-slug>/2-month/
public/logsheets/<domain-slug>/3-month/
public/logsheets/<domain-slug>/6-month/
```

Example:

```text
public/logsheets/data-science-with-python/3-month/weekly-logsheet.xlsx
```

Use lowercase kebab-case for domain folder names. When a new domain is added, create all four duration folders for it.
